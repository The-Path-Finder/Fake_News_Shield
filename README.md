# Fake News Shield

**Team:** Hallucination Handlers (AIP303 — Natural Language Processing Lab, IIIT Kota)

Real-Time Multilingual Misinformation & Fake News Screening built with **spaCy**, **TF-IDF (unigrams & bigrams)**, **Linear SVM**, and **Streamlit**.

## Files
- `app.py` — Streamlit web application with embedded HTML/CSS verification desk UI.
- `preprocessing.py` — Language detection (`langdetect` + Devanagari script check) and spaCy tokenization, stop-word removal, and lemmatization.
- `linear_svm_model.pkl` & `tfidf_vectorizer.pkl` — Pre-trained LinearSVC model and 10,000-feature TF-IDF vectorizer.
- `requirements.txt` — Python dependencies for local execution and Streamlit Community Cloud deployment.

## Run Locally
```bash
streamlit run app.py
```

> **Disclaimer:** Predictions are generated by an automated ML/NLP model and are not verified fact-checks.
