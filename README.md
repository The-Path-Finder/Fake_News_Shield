# 🛡️ Fake News Shield — Real-Time Multilingual Misinformation & Fake News Shield

**Team Name:** Hallucination Handlers (AIP303 — Natural Language Processing Lab, IIIT Kota)

An end-to-end NLP & Machine Learning system for screening news articles in real time using **spaCy** preprocessing, **TF-IDF (unigrams & bigrams)**, **Linear SVM**, a **FastAPI** `/predict` backend, a **Vite + React** web frontend, and a **Chrome Extension**.

## Project Structure

- `preprocessing.py` — Language detection (`langdetect` + Devanagari script check) and **spaCy** tokenization, lowercasing, stop-word removal, and lemmatization.
- `backend/main.py` — FastAPI server exposing `/health`, `/model-info`, and `POST /predict` with confidence-threshold checking (`Likely Real`, `Likely Fake`, `Low Confidence`).
- `frontend/` — Vite + React web application for analyzing English & Hindi news articles, inspecting pipeline stages, and viewing session history.
- `chrome-extension/` — Manifest V3 Chrome Extension ("Scan This Article") that extracts article text from the active tab and sends it to the FastAPI backend.
- `linear_svm_model.pkl` & `tfidf_vectorizer.pkl` — Pre-trained LinearSVC classifier and 10,000-feature TF-IDF vectorizer.
- `app.py` — Original Streamlit interface from the repository.

## Running Locally

### 1. Start the FastAPI Backend
```bash
.venv/bin/uvicorn backend.main:app --reload --host 0.0.0.0 --port 8000
```

### 2. Start the Vite React Frontend
```bash
cd frontend
npm run dev
```
Open the local Vite URL (e.g. `http://localhost:5173`). Vite proxies `/api/*` requests to `http://127.0.0.1:8000`.

### 3. Load the Chrome Extension
1. Open `chrome://extensions` in Chrome and enable **Developer mode**.
2. Click **Load unpacked** and select the `chrome-extension/` folder.
3. Open any news article and click **Scan This Article**.

> **Disclaimer:** Predictions are generated by an automated ML/NLP model and are **not** verified fact-checks. Always cross-check claims with trusted news and fact-checking sources.
