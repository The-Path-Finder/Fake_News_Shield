# Fake News Shield

**Team:** Hallucination Handlers (AIP303 — Natural Language Processing Lab, IIIT Kota)

Real-Time Multilingual Misinformation & Fake News Screening built with **spaCy**, **TF-IDF (unigrams & bigrams)**, **Linear SVM**, **Streamlit**, **FastAPI**, and a **Chrome Extension**.

## Files
- `app.py` — Streamlit web application with editorial Verification Desk UI, confidence-threshold check (`Likely Real`, `Likely Fake`, `Low Confidence`), and trusted-source links.
- `api.py` — FastAPI backend exposing `GET /health` and `POST /predict` for the Chrome extension.
- `chrome-extension/` — Manifest V3 Chrome extension ("Scan This Article") that extracts article text and calls `/predict`.
- `preprocessing.py` — Language detection (`langdetect` + Devanagari script check) and **spaCy** tokenization, lowercasing, stop-word removal, and lemmatization.
- `train.py` — Offline model training and evaluation comparing **Logistic Regression**, **Multinomial Naive Bayes**, and **Linear SVM**.
- `linear_svm_model.pkl` & `tfidf_vectorizer.pkl` — Pre-trained LinearSVC classifier and 10,000-feature TF-IDF vectorizer.

## Deployment Target (Streamlit Community Cloud)
1. Push this repository to GitHub (`khadoriarohit/Fake_News_Shield`).
2. Sign in at [share.streamlit.io](https://share.streamlit.io) and click **Create app**.
3. Select repository `khadoriarohit/Fake_News_Shield`, branch `main`, and main file `app.py`.
4. Under **Advanced settings**, choose Python `3.11` or `3.12` and click **Deploy**.

## Chrome Extension + FastAPI Backend
1. Start the FastAPI backend locally (or host `api.py` on Render / Hugging Face Spaces for HTTPS):
   ```bash
   uvicorn api:app --host 0.0.0.0 --port 8000
   ```
2. Open `chrome://extensions` (or `brave://extensions`), enable **Developer mode**, click **Load unpacked**, and select `chrome-extension/`.
3. Open any news article and click **Scan This Article**.

> **Disclaimer:** Predictions are generated by an automated ML/NLP model and are not verified fact-checks.
